# Vibesomnia 0.1.0-alpha.5 — Private installer preview

A universal macOS app for keeping an AI workspace awake, including on-demand
closed-lid sessions without Amphetamine.

**Private alpha test release.** The app is ad-hoc signed; the package installer
is unsigned and not notarized. This is not a general-distribution or beta build.
The repository stays private while acceptance testing continues.

## Download and install

Download `Vibesomnia-0.1.0-alpha.5-universal-local-unsigned.dmg` from the assets below.
The adjacent `.sha256` file records its checksum. Supports macOS 14+ with both
Apple silicon and Intel executable slices; Intel hardware testing is still pending.

1. End or recover any Vibesomnia session, then quit Vibesomnia.
2. Open the DMG and **Install Vibesomnia.pkg** to install to Applications.
3. Open Vibesomnia from Applications and follow first-run setup.
4. Test your existing remote connection with the lid open before starting a
   closed-lid session and approving its macOS administrator prompt.

Gatekeeper may block this unsigned, unnotarized test build. Developer ID signing
and notarization remain release gates. Installation does not enable remote access
or start a power session automatically.

## Included

- Native keep-awake sessions, timers, app-lifetime rules and battery protection.
- Standalone closed-lid guard with owned state and heartbeat-based restoration.
- ChatGPT/Claude desktop discovery, app launch controls, and a same-user CLI.
- Reviewed user scripts, source editor, manual runs, and session hooks.
- Universal DMG/pkg, first-run setup, and saved display/closed-lid/battery choices.

## Verification and limits

- 23 automated tests and CI passed for this version.
- DMG checksum/integrity, package destination, signatures, executable architectures,
  deployment targets, resources and version metadata verified locally.
- Setup preview and installer introduction/license screens checked through computer use.
- Earlier guard tests restored sleep on normal stop, app exit and heartbeat expiry.
- An initial physical closed-lid observation on the still-running **alpha.4**
  confirmed the lid was closed and both desktop apps remained running. The owner
  reported it seemed to work; complete remote interaction/repeated-cycle acceptance
  is not yet established. This was not a physical test of installed alpha.5.

Full installation/upgrade, first launch from Applications, clean-Mac Gatekeeper
handling, charger transitions, wider hardware testing and remote reconnection
remain pending. Full Amphetamine parity and built-in remote desktop are not complete.
Use your existing remote-access tool; Vibesomnia does not enable SSH or expose a listener.
