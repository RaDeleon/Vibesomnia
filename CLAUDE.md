# Vibesomnia

Read and follow [AGENTS.md](AGENTS.md), the shared instruction source for this
repository. It applies equally to Claude Code, Codex, and other coding agents.

Start with README.md, VERSION, changelog.md, and the latest sessionlog.md entry.
Build with `./script/build_and_run.sh --verify`; test with `swift test`.

The current product is fully open source and beta. Community/Pro separation is
backlogged. Respect power-session ownership, explicit recovery, permission
boundaries, and the distinction between native idle-sleep prevention and the
administrator-authorized temporary closed-lid guard and reviewed user add-ons. Do not imply remote desktop is complete.

Append what you changed and verified to sessionlog.md before finishing a session.
